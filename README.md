SOLARA HEAT is an original open-world crime game set in the fictional coastal city of Solara Bay, built with three.js. Walk or drive a city grid, steal cars, run story missions, take cab fares, and outrun a 1–5 star police pursuit system — with traffic AI, pedestrians, a minimap HUD, synthesized audio, and local saves, all playable offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (`node main.ts` builds the make.fun hand-in dossier instead.)
